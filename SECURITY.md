# Security

Report a vulnerability privately to anonb3ll@pm.me. Do not open a public issue for it.

Include the commit you tested, what an attacker can do, and whether the extension must already be installed. Please allow time for a fix before any public write-up.

Exocortex is a local extension and a local MCP process. It does not have a hosted account or a server to take down. Capture stays off until the side-panel toggle is on, and the privacy guard is fail-closed: a change that lets a blocked URL or a secret through is a vulnerability.
